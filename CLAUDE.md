# Lekh — standing rules

- Bump the patch version in `package.json` on every app change, however minor, then run `npm install` to sync `package-lock.json`. The version is shown in the About sheet (`src/components/AboutSheet.tsx`) via `__APP_VERSION__`. There is no footer — the app has no page furniture, and anything of this kind belongs in the About sheet behind the ⓘ.

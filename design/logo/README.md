# Lekh Patro — logo

**The hanging page.** A calendar page whose crimson header is the शिरोरेखा of
ले: ल hangs from the header's bottom edge, and the े matra rises from its top
edge as the hook the page hangs by. Writing and the patro, in one letter.

Adopted 2026-10-10 (v1.9.56), replacing ले + a typing caret. Generated by
[`build_mark.py`](build_mark.py) — edit the geometry there and re-run, never
the SVGs by hand.

## Files

| File | Use |
|---|---|
| `mark.svg` | The mark on light grounds: ink page, crimson `#C8102E` header |
| `mark-on-dark.svg` | On dark grounds: paper page, crimson `#F87171` header |
| `mark-black.svg` / `mark-white.svg` | One colour — print, stamps, embossing, anywhere colour is not available |
| `lockup.svg` / `lockup-on-dark.svg` | Mark + लेख/पात्रो wordmark (outlined), as in the app bar |
| `app-icon.svg` | Full-bleed square tile — the source of every launcher/PWA/Play icon |
| `app-icon-maskable.svg` | PWA `maskable`: the mark inside the 80 % safe circle |
| `favicon.svg` | Rounded tile, mark enlarged — the 16/32 px cut |

ल is a **hole** in the page in every version, not a painted shape, so it is
always the colour of whatever is behind the page.

## Colour

| | Hex | Where |
|---|---|---|
| Tile | `#151A2B` | App-icon ground; ink on light grounds |
| Paper | `#F2F4F8` | Page and matra on dark grounds |
| Crimson (dark ground) | `#F87171` | Header on dark — the app's `--dark-accent` |
| Crimson (light ground) | `#C8102E` | Header on light — the app's light `--accent` |

The flag red `#C8102E` goes muddy on the dark tile, which is why the header
changes shade with the ground. Same rule as the app's two accents.

## One colour

The one-colour version cannot separate the header from the page by colour, so
a knocked-out line does it instead — inset from both edges, so it reads as the
letter's headline drawn in negative, with ल hanging from it. This is also the
Android 13+ themed-icon layer (`ic_launcher_monochrome.xml`).

## Clear space and size

- **Clear space:** one header height (34 units of the 256 grid, ≈ 19 % of the
  page width) on every side, measured from the page and the matra's tip.
- **Minimum size:** 24 px tall for the mark, 20 px tall for a lockup's
  wordmark. Below 24 px use `favicon.svg`, which drops the margin to keep ले
  legible — it is checked down to 16 px.

## Don't

- Re-set ले in a font. The joins are built: the matra's foot sits *on* the
  header's top edge and ल's stem starts *at* its bottom edge.
- Put the paper version on a light ground or the ink version on a dark one —
  the page disappears. Use the matching file.
- Recolour the header to a Material You / wallpaper colour. The launcher icon
  is the brand; Material You reaches it only through the monochrome layer.
- Add a Latin "Lekh" beside the Devanagari wordmark — never the same word in
  two scripts side by side.
- Outline, shadow, gradient, or rotate it.

## Type

Letterforms are Noto Sans Devanagari Bold (SIL Open Font License 1.1 — fine
for a logo), copied in as outlines. The wordmark in the lockups is the same
family, shaped by Inkscape so त्र and ो come out right, then outlined.
Trademark clearance has not been searched.
